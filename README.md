# 闪记 PC 功能演示

根目录的 `index.html` 是思必驰闪记 `release-3.3.0-pc` 真实 Flutter Web 构建，可直接通过 GitHub Pages 分享：

<https://zhengxianlu181-blip.github.io/shanj-demo/>

当前构建包含：

- 首页“开始录音”和“文件导入”入口
- 实时录音、暂停/继续、结束确认、计时和逐句转写
- 说话人、时间戳、字幕设置和字幕浮窗入口
- MP3、WAV、M4A、MP4、MOV 文件选择/拖拽、播放预览、上传、转写、保存和失败重试
- 实时录音和文件导入共用的录音详情页

## 设计评审版

如果需要查看录音工作流的交互状态和“自定义总结”弹窗，可打开：[设计评审版](./design-review.html)。该页面用于 UI 评审，不替代根目录的真实 Flutter 功能构建。

在线页面受浏览器能力限制：真实麦克风、登录、ASR 服务和上传接口仍需要对应环境与权限；Windows 原生字幕浮窗的置顶、拖动、最小化和完整设置请在源码仓库运行 PC 端：

```text
cd apps/app_main
flutter run -d windows
```

根目录的真实 Flutter 构建用于功能演示；`design-review.html` 用于页面布局、状态和交互评审。
## 录音与实时转录 Demo

新增的 [recording-demo.html](./recording-demo.html) 沿用当前 PC 端页面壳、侧边导航、顶部工具栏、颜色和组件规范，提供一条可直接演示的录音工作流：

- 工作台进入实时录音或本地文件导入；录音流程包含权限检查、计时、波形、逐句 Demo 转录、暂停/继续、结束确认、保存失败重试。
- 录音页提供“模拟断网 / 恢复网络”测试入口。断网时采集状态、计时、波形和转录同步暂停；恢复后必须手动继续。
- 悬浮字幕支持拖动、置顶、最小化、关闭/重新打开，以及字体、颜色、透明度、位置和说话人显示设置。
- 文件导入使用真实浏览器文件选择器和拖拽，校验 MP3、WAV、M4A、MP4、MOV，模拟上传、解析、转录、保存和失败重试。
- 实时录音和文件导入共用统一详情页，支持音频/视频预览、播放进度、逐句定位和复制转录。

在线访问（GitHub Pages）：

<https://zhengxianlu181-blip.github.io/shanj-demo/recording-demo.html>

本地预览（无需 PowerShell，可使用任意静态文件服务器）：

```text
打开 recording-demo.html
```

页面中的转录内容、上传处理和保存结果均明确标记为 Demo 模拟数据；用户选择的文件只在浏览器本地预览，不会上传到第三方服务。
